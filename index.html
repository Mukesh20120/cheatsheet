Adding a sheet

Two moves, no tooling. The site is plain static files — whatever you drop in is what gets served.

Step 1 · the file

Put a self-contained .html file in the sheets/ folder. Lowercase, hyphenated name.

sheets/
  github-actions.html
  docker.html        ← your new one
Step 2 · the link

Open index.html, find the TEMPLATE comment inside the shelf, copy that block above it and fill in the four fields.

href   → sheets/docker.html
idx    → 02
h2     → Docker
p      → topics, for the filter
Step 3 · ship

Commit and push. GitHub Pages redeploys on its own.

git add .
git commit -m "add docker sheet"
git push
